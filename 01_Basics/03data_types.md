# 03 - Data Types

Python provides different data types for storing different kinds of values.

## Common Types
- `int` - whole numbers
- `float` - decimal numbers
- `str` - text
- `bool` - `True` or `False`
- `list` - ordered, mutable collection
- `tuple` - ordered, immutable collection
- `set` - unordered collection of unique values
- `dict` - key-value pairs

## Check a Type
```python
x = 10
print(type(x))
```

## Example
```python
age = 20              # int
price = 99.5          # float
name = "Tarun"        # str
is_student = True     # bool
```
