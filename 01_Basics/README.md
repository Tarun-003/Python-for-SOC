# 🐍 Python Basics

This module covers the fundamental concepts of Python required for cybersecurity and SOC automation. It provides the programming foundation needed to build scripts for log analysis, network automation, and security tools.

---

## 🎯 Learning Objectives

- Understand Python syntax
- Work with variables and data types
- Accept user input
- Use operators and conditional statements
- Implement loops and functions
- Work with Python collections
- Handle exceptions and errors

---

## 📚 Topics Covered

- Hello World
- Variables
- Data Types
- User Input
- Operators
- If-Else
- For Loop
- While Loop
- Functions
- Lists
- Tuples
- Dictionaries
- Sets
- Strings
- Type Casting
- Comments
- Exception Handling

---

## 🛡️ Why This Module?

Python is widely used in cybersecurity to automate repetitive tasks, analyze logs, process data, and develop security tools. Mastering these basics is the first step toward becoming a SOC Analyst.
