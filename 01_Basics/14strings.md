# 14 - Strings

A string is a sequence of characters enclosed in quotes.

## Example
```python
name = "Tarun"
```

## Indexing
```python
print(name[0])
print(name[-1])
```

## Slicing
```python
print(name[1:4])
```

## Common Methods
```python
text.upper()
text.lower()
text.strip()
text.replace("old", "new")
text.split()
text.startswith("H")
text.endswith("!")
```

## f-Strings
```python
name = "Tarun"
age = 20

print(f"My name is {name} and I am {age} years old.")
```
