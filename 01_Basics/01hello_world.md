# 01 - Hello World

## What is Python?
Python is a high-level, interpreted programming language known for simple and readable syntax.

## First Program
```python
print("Hello, World!")
```

## Key Points
- `print()` displays output on the screen.
- Python statements normally do not require `;`.
- Python uses indentation to define code blocks.

## Example
```python
print("Hello Tarun!")
print("Welcome to Python")
```
