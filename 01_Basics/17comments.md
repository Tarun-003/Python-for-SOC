# 17 - Comments

Comments are notes written inside code that Python does not execute.

## Single-Line Comment
```python
# This is a comment
print("Hello")
```

## Multi-Line Documentation
Triple-quoted strings are commonly used for docstrings:

```python
def add(a, b):
    """Return the sum of two numbers."""
    return a + b
```

## Why Use Comments?
- Explain difficult logic.
- Improve code readability.
- Document important decisions.
- Help other developers understand the code.
