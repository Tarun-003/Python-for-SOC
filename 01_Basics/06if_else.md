# 06 - if-else

Conditional statements allow a program to make decisions.

## Syntax
```python
if condition:
    # code
elif another_condition:
    # code
else:
    # code
```

## Example
```python
age = int(input("Enter your age: "))

if age >= 18:
    print("Eligible")
else:
    print("Not eligible")
```

## Key Point
Python uses indentation to define the body of `if`, `elif` and `else`.
