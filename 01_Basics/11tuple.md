# 11 - Tuple

A tuple is an ordered collection that cannot normally be changed after creation.

## Creating a Tuple
```python
data = (10, 20, 30)
```

## Access Elements
```python
print(data[0])
```

## Tuple Methods
```python
data.count(10)
data.index(20)
```

## Key Point
Tuples are immutable, unlike lists.

## Single-Element Tuple
```python
x = (10,)
```
