# 04 - User Input

`input()` is used to take input from the user.

## Syntax
```python
name = input("Enter your name: ")
```

## Important
`input()` returns data as a string.

## Converting Input
```python
age = int(input("Enter your age: "))
marks = float(input("Enter your marks: "))
```

## Example
```python
name = input("Enter your name: ")
print("Hello", name)
```
