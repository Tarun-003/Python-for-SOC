# 05 - Operators

Operators are symbols used to perform operations on values.

## Arithmetic Operators
`+`, `-`, `*`, `/`, `//`, `%`, `**`

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

## Comparison Operators
`==`, `!=`, `>`, `<`, `>=`, `<=`

## Logical Operators
- `and`
- `or`
- `not`

## Assignment Operators
`=`, `+=`, `-=`, `*=`, `/=`

## Membership Operators
- `in`
- `not in`

## Identity Operators
- `is`
- `is not`
