# 13 - Set

A set is an unordered collection of unique elements.

## Creating a Set
```python
numbers = {1, 2, 3, 4}
```

## Add and Remove
```python
numbers.add(5)
numbers.remove(2)
```

## Set Operations
```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # union
print(a & b)  # intersection
print(a - b)  # difference
```

## Key Point
Sets automatically remove duplicate values.
