# Python Basics - Practice Set

Use these questions to test your understanding of the basics.

## Variables & Input
1. Print your name, age and course.
2. Take two numbers from the user and print their sum.
3. Take the user's name and print a welcome message.

## Operators
4. Write a program to calculate the area of a circle.
5. Check whether a number is even or odd.
6. Calculate the remainder and quotient of two numbers.

## Conditions
7. Check whether a person is eligible to vote.
8. Find the largest of two numbers.
9. Create a simple grade calculator using `if-elif-else`.

## Loops
10. Print numbers from 1 to 10 using a `for` loop.
11. Print the multiplication table of a number.
12. Calculate the sum of numbers from 1 to N.
13. Use a `while` loop to count from 10 down to 1.

## Functions
14. Create a function to add two numbers.
15. Create a function to check whether a number is prime.
16. Create a function that returns the factorial of a number.

## Collections
17. Find the largest value in a list.
18. Remove duplicate values from a list using a set.
19. Create a dictionary containing student information and print each key-value pair.

## Strings
20. Count the number of characters in a string.
21. Reverse a string.
22. Check whether a string is a palindrome.

## Exception Handling
23. Write a program that safely handles division by zero.
24. Write a program that handles invalid integer input.
