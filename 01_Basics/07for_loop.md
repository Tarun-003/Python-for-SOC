# 07 - for Loop

A `for` loop is used to repeat code for each item in a sequence.

## Example
```python
for i in range(1, 6):
    print(i)
```

## Loop Through a List
```python
names = ["Tarun", "Rahul", "Arun"]

for name in names:
    print(name)
```

## range()
```python
range(5)        # 0 to 4
range(1, 6)     # 1 to 5
range(1, 10, 2) # 1, 3, 5, 7, 9
```
