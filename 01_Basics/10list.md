# 10 - List

A list stores multiple values in an ordered and mutable collection.

## Creating a List
```python
numbers = [10, 20, 30, 40]
```

## Access Elements
```python
print(numbers[0])
print(numbers[-1])
```

## Common Methods
```python
numbers.append(50)
numbers.insert(1, 15)
numbers.remove(30)
numbers.pop()
numbers.sort()
numbers.reverse()
```

## Slicing
```python
print(numbers[1:4])
```

## Key Point
Lists are mutable, meaning their elements can be changed.
