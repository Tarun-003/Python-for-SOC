# 🛡️ Python for SOC (Security Operations Center)

Welcome to **Python for SOC**, a collection of Python scripts created to automate common tasks performed by Security Operations Center (SOC) analysts. This repository is part of my cybersecurity learning journey and focuses on building practical skills in Python, Linux, networking, and security automation.

- Learn Python by solving real cybersecurity problems.
- Automate repetitive SOC tasks.
- Improve log analysis and threat detection skills.
- Build a strong GitHub portfolio for cybersecurity careers.
